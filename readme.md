# Omnitech Hydra

My project portfolio repo, it's easy to install, but in terms of proper modification from what i've built so far, you will might as well need a texture editor tool to make changes to OS interface.

<br>

To setup a dev environment:

```bash
# Clone the repositor

# Install dependencies 
npm i

# Run the local dev server
npm run dev
```

To serve a production build:

```bash
# Install dependencies if not already done - 'npi i'

# Build for production
npm run build

# Serve the build using express
npm start
```
